CloudGuard

GCP misconfiguration scanner

Live site Source

Scans a Google Cloud project for the misconfigurations behind real breaches, scores it from 0 to 100, and explains how to fix every finding.

  • 4 independent detection modules on the Cloud Storage, IAM, Cloud Logging and Compute Engine APIs, normalised into one findings schema and a severity-weighted 0–100 risk score.
  • Least privilege by hand: GCP's predefined Viewer role leaves out storage.buckets.getIamPolicy, so two custom IAM roles give the scanner's service account exactly 6 read-only permissions.
  • Protocol-aware firewall auditor: separates TCP, UDP and ICMP to flag SSH, RDP and database ports open to 0.0.0.0/0, and skips ICMP rules so they never become false positives.

RISKY_PORTS = {
    "22": "SSH", "3389": "RDP", "3306": "MySQL",
    "5432": "PostgreSQL", "27017": "MongoDB",
    "6379": "Redis", "9200": "Elasticsearch",

OPEN_TO_WORLD = "0.0.0.0/0"

def evaluate_rule(rule):
    findings = []

    if rule.direction != "INGRESS" or rule.disabled or not rule.allowed:
        return findings
    if OPEN_TO_WORLD not in rule.source_ranges:
        return findings

    for allowed in rule.allowed:
        protocol = allowed.I_p_protocol.lower()

        if protocol == "icmp":
            continue

        if protocol == "all":
            findings.append({
                "severity": "CRITICAL",
                "description": "ALL protocols and ports open to the entire internet",
            })
            continue

        if protocol in ("tcp", "udp"):
            ports = list(allowed.ports) if allowed.ports else None

            if ports is None:
                findings.append({
                    "severity": "HIGH",
                    "description": f"ALL {protocol.upper()} ports open to the entire internet",
                })
            else:
                for port in ports:
                    if port in RISKY_PORTS:
                        findings.append({
                            "severity": "HIGH",
                            "description": f"{protocol.upper()} port {port}"
                            f" ({RISKY_PORTS[port]}) open to the entire internet",
                        })

    return findings
SEVERITY_WEIGHTS = {
    "CRITICAL": 20,
    "HIGH": 10,
    "MEDIUM": 5,
    "LOW": 2,
}

def run_all_scans(project_id=PROJECT_ID):
    """Runs every scanner and returns one combined list of findings."""
    all_findings = []
    all_findings += scan_buckets(project_id)
    all_findings += scan_iam(project_id)
    all_findings += scan_logging(project_id)
    all_findings += scan_firewalls(project_id)
    return all_findings

def calculate_score(findings):
    """Starts at 100, deducts points per finding based on severity."""
    score = 100
    for f in findings:
        score -= SEVERITY_WEIGHTS.get(f["severity"], 0)
    return max(score, 0)

def grade_for_score(score):
    if score >= 90:
        return "Excellent"
    elif score >= 70:
        return "Good"
    elif score >= 50:
        return "Needs Improvement"
    else:
        return "Critical Risk"

Campus Bazaar

Anonymised campus marketplace

Live site Source

A marketplace only for NSUT students to trade notes, books and hostel gear, or find academic help, under anonymous usernames.

  • Sign-in locked to @nsut.ac.in by a database trigger, so the rule can't be bypassed by editing the frontend. Real names and Google photos are never copied.
  • Row-Level Security on every table. Listing-scoped buyer–seller chat runs on Supabase Realtime (WebSockets) under the same policies, so students only read their own conversations. Not even admins can open private chats.
  • Server-side Gemini moderation of listing text and images returns a structured JSON verdict. Only the server can make a listing live; flagged ones land in a role-based admin dashboard for human review.

async def connect_server(self, name, command, args, env=None):
    """Connect to an MCP server via stdio transport."""
    server_params = StdioServerParameters(command=command, args=args, env=env)

    # Create stdio transport
    stdio_transport = await self._exit_stack.enter_async_context(
        stdio_client(server_params)
    )
    read_stream, write_stream = stdio_transport

    # Create and initialize session
    session = await self._exit_stack.enter_async_context(
        ClientSession(read_stream, write_stream)
    )
    await session.initialize()

    # Discover available tools
    tools_response = await session.list_tools()
    tools = {
        tool.name: {
            "name": tool.name,
            "description": tool.description or "",
            "parameters": tool.inputSchema if hasattr(tool, "inputSchema") else {},
        }
        for tool in tools_response.tools
    }

    self._servers[name] = MCPServerConnection(name=name, session=session, tools=tools)
